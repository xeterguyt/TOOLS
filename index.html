How to Use
A quick guide to TitleData Manager.

Adding a Title

  1. Go to the Titles page.
  2. Enter a key — this is the Lua table key, e.g. Evil_Path. Use underscores, no spaces.
  3. Enter a display string — supports color parser syntax (see below).
  4. Optionally add a desc.
  5. Add data & price type entries — click "Add price type entry", pick the type (e.g. Badges), and enter the value/ID. One entry = that type. Two or more = Mixed.
  6. Click Add title.

Adding a Rank

  1. Go to the Ranks page.
  2. Enter a level number (e.g. 3 or 2.1).
  3. Enter a display string.
  4. Click Add rank.

Editing / Removing

  • Desktop: Right-click any entry, or hover and click the ⋮ button.
  • Mobile: Hold/long-press any entry to open options.

Color Parser Syntax

  • Inline (one word): Word{"{"}color<255,0,0>{"}"}
  • Whole sentence: My Title //sentence{"{"}color<255,0,0>{"}"}
  • Gradient: //sentence{"{"}color<255,0,0 | 0,0,255>{"}"}
  • Font: //sentence{"{"}font<GothamBold>{"}"}
  • Style: //sentence{"{"}style<bold | italic>{"}"}

Exporting

  • Go to Export Lua — copy or download the full TitleData.lua file ready for Roblox Studio.
  • Go to Import / Export to save/load a JSON backup.

Audit Log

Every change (add, edit, remove) is logged with a timestamp. The log is stored locally only. You can select and copy specific lines if you need to recover something.
